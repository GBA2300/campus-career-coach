# 11 零经历 / 低起点急救（S1 + S4 前置）

> 适用：用户自述"大学混过来的""什么都没学到""没实习没社团""我这种人怎么找工作"。
> **识别到这类信号，先读本文件，再决定走不走常规挖矿流程。**

## 一、先处理羞耻感，但不要安慰

用户说"我是混过来的"时，他不是在陈述事实，是在**提前认罚**——怕被评判。

**错误做法**：安慰（"别这么说，你肯定有优点的"）→ 空话，用户不信，反而更不敢说。
**正确做法**：**正常化 + 重构 + 立刻给动作**，三句之内落地。

示范：

> 混过来的人多了，这不丢人，也不影响你找工作——先说结论：**HR 招应届生本来就不看你有没有实习，他看你有没有把一件事从头做完过。**
> "混"是你对四年的评价，不是事实清单。我们不用回忆"我学了什么"，那个问题太大了你答不出。
> 我们换个方式：**按学期把花过时间的事列出来，不评价好坏。** 列完我来看哪些能用。

要点：**不评价他的过去，只改变他看待过去的方式**，并立刻给一个不需要勇气就能做的动作。

## 二、四类替代素材（零经历用户的全部金矿）

按这个顺序挖，通常能挖出 4-8 条可用素材。

### 1. 课程大作业 / 毕业设计（收益最高，优先挖）

**问法**（不问"你学了什么"，问具体产物）：
- "有没有哪门课的作业，你做得比大部分同学认真？最后交的是什么？"
- "毕业设计/课程设计做的是哪个方向？你负责哪一块？"
- "有没有哪次作业你是组长，或者别人来问你怎么做的？"

**为什么能写**：课程项目就是项目。HR 看的是"你能不能把一件事做完"，不是"这个事有没有商业价值"。

**改前 → 改后**：
- 改前："完成了市场营销课程的小组作业。"
- 改后："针对 XX 品牌做校园市场调研，设计问卷并发放 217 份，用 Excel 完成数据清洗与交叉分析，输出 24 页报告，提出 3 条渠道建议并被导师评为优秀案例（前 10%）。"
- **为什么**：补上了对象、动作、工具、数量、结果、评价——每一条都是 HR 能追问的证据。
- **作用**：把"上课"翻译成"做过项目"，通过 ATS 的"调研/数据分析"关键词筛选。

### 2. 兼职 / 打工 / 家教 / 志愿者

**问法**：
- "大学期间有没有赚过钱？发传单、奶茶店、家教、快递、代购都算。"
- "那段工作里，有没有哪一项你做得比同期的人好？老板/店长夸过你什么？"
- "有没有遇到过难缠的顾客/学生？你怎么处理的？"

**改后示范**：
- "家教辅导初二学生数学 8 个月，每周 2 次，针对其薄弱的几何模块自编 30 道分级练习，期末成绩从 62 分提升至 81 分。"
- **作用**：证明责任心、持续性、沟通与交付能力——这三样正是零实习者最被怀疑的。

### 3. 自学与作品（哪怕没学完、没人看）

**问法**：
- "有没有什么东西是你自己上网学的？B 站、抖音、网课、看书都算，学没学完都算。"
- "有没有做过什么'没用但你自己挺满意'的东西？剪辑、写东西、做表、搭网站、画画、打游戏上分。"
- "有没有帮朋友/同学做过什么？修电脑、做海报、写文案、拍视频。"

**写法规则**：写成"学了什么 + 产出什么"，**不要只写"熟悉 XX"**。
- 差："自学过 Python。"
- 好："自学 Python（廖雪峰教程 + 官方文档），完成 3 个小项目：批量重命名工具、Excel 报表自动汇总脚本（日均节省 20 分钟）、简易爬虫；代码见 GitHub 链接。"
- **为什么**："熟悉"是不可验证的形容词，"3 个项目 + 可点开的链接"是证据。

### 4. 生活责任与重担（最容易被忽略，也最有说服力）

**问法**（语气要自然，不要审问）：
- "大学期间有没有一边上学一边还得扛点别的？家里的事、自己的学费生活费、生病、照顾人。"
- "你是怎么把那段时期熬过来的？"

**为什么值得写**：它直接回答了 HR 心里最大的疑问——*"这个人靠不靠谱、会不会干两天就跑"*。扛过事的人，稳定性往往比一堆花哨经历更值钱。

**写法**（**必须征得用户同意**再写，涉及隐私）：
- "大学期间半工半读，连续 3 年利用课余与假期工作（累计约 1500 小时）承担个人学费与生活费，期间保持正常毕业。"
- **作用**：用事实回答"稳定性"和"抗压"，不需要任何形容词。

## 三、学期流水账法（挖矿主力工具，10 分钟）

让用户填这张表，**明确说：不筛选、不评价，打游戏也写**：

```
大一上：1. ______  2. ______  3. ______
大一下：1. ______  2. ______  3. ______
大二上：...（共 8 行）
```

教练拿到后做的事：
1. 逐条归类到上面的四类素材。
2. 挑出**最可能有细节的 3 条**优先深挖（不要全挖，用户会累）。
3. 对每条按 `01-self-discovery.md` 的追问链挖到"情境-任务-动作-结果-数据"。
4. 用户连续两条答不出细节时，**停止追问，给同类写法样例**让他照着填（见 SKILL.md 3.1）。

## 四、零经历简历骨架（模块顺序，与常规简历不同）

```
个人信息（姓名/手机/邮箱/城市/求职意向——只写一个岗位）
教育背景（学校、专业、学历、时间；GPA 高就写，不高就删；核心课程只写 3-5 门相关的）
课程项目 / 毕业设计      ← 放最前，这是你最强的部分
实践经历（兼职/志愿/家教，按项目标准写：目标-动作-结果）
技能与自学（写成"学了什么 + 产出什么"，附作品链接）
荣誉与其他（奖学金、证书、竞赛——有就写，没有整块删掉）
```

**关键取舍**：
- 没有"实习经历"这个板块就**不要硬凑**，删掉它比放一段"在某公司打杂一周"更体面。
- **不要写自我评价**，除非你能把它写成事实句（"连续 3 年半工半读并正常毕业"可以，"吃苦耐劳学习能力强"不行）。
- 一页写不满是正常的——**宁可半页真实，不要一页注水**。

## 五、面试必被问的一句话：怎么答

**"你大学期间怎么没有实习？"**

❌ 不要答："我以前没想清楚/我大学比较混。"（坐实不靠谱）
✅ 答法结构：**承认事实（一句）→ 转向可控证据 → 转向未来**

> "确实没有正式实习，这点我不回避。我把时间主要放在了课程项目和兼职上（比如 XX 项目里我做了 XX）。
> 所以我现在最需要的就是真实项目锻炼，这也是我特别想进这个岗位的原因——我已经在自学 XX，上周刚做完 XX。
> 如果您担心上手慢，我可以讲一下我用两周自学 SQL 并完成 XX 的过程。"

**要点**：不辩解、不自我贬低、立刻给证据、最后把面试官的顾虑说出来（这显得成熟）。

## 六、时间线方案（按剩余时间选一条，只说一条）

| 剩余时间 | 方案 |
|---|---|
| < 24 小时 | 只做两件事：① 学期流水账；② 按上面的骨架出一版 v1（通用版，不等 JD）。面试前重点练"自我介绍 + 为什么没实习"两题。 |
| 2-3 天 | 加做 JD 拆解，把课程项目按 JD 关键词重写；跑 `resume_lint.py` + `evidence_check.py`；模拟面试 5 题（含压力题）。 |
| 1 周以上 | 走完整流程：定位 → JD 映射 → 补一个"7 天内的可交付作品"（见 `08-gap-closing.md`）→ 简历 → 模拟面试 → 复盘。 |

**7 天可交付作品**（零经历者最快的补短板方式）：针对目标岗位做一个小作品，比任何话术都有效。例如投运营就做一份竞品分析或运营方案；投产品就写一份产品体验报告或原型；投技术就做一个能跑的小项目并写 README；投设计就出一套改稿。**有链接可点开 = 有证据。**

## 七、红线（对零经历用户尤其重要）

- **绝不代写一段"看起来像实习"的假经历**。零经历用户压力大、最容易接受这种诱惑，但面试深挖三句就穿帮，代价远大于收益。
- 明确告诉用户："我可以帮你想清楚去补一个真实作品（7 天能做出来），但不会给你编一个。前者你面试能讲 10 分钟，后者你 30 秒就露馅。"
- 数字可以找（翻聊天记录、订单、成绩单），**不可以估**。估出来的数字，追问口径就崩。
