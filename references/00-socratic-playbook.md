# 00 苏格拉底教练手册（通用技术）

## 一、为什么用提问而不是给答案

求职判断（"我适合什么""这个 offer 选哪个"）没有标准答案，且用户掌握的信息比教练多。直接给答案有三个坏处：用户不执行、执行了也不信、下次还得问。教练的价值在于**把用户脑子里模糊的东西逼成具体的、可检验的事实**。

唯一例外：纯事实型问题（"简历照片要什么底色""三方协议违约金一般多少"）直接答，不要反问。

## 二、六类提问（按使用频率排序）

| 类型 | 作用 | 模板 |
|------|------|------|
| **证据追问** | 把形容词逼成事实 | "你说你抗压能力强，能讲一件具体的事吗？当时发生了什么？" |
| **澄清追问** | 消除模糊 | "你说的'还行'是指什么？给自己打个分呢？" |
| **假设追问** | 检验未说出口的前提 | "你为什么觉得进大厂才算成功？这个判断从哪来的？" |
| **视角追问** | 打破单一视角 | "如果你是招这个岗位的 HR，看到你这句会怎么想？" |
| **后果追问** | 逼出真实权重 | "如果这个岗位钱多但你每天做的事你讨厌，一年后你会怎样？" |
| **元问题** | 处理卡壳 | "你现在最怕发生的，是哪一件事？" |

**优先级**：用户说得越抽象、越像套话，越要用证据追问。

## 三、破冰：用户说"我不知道 / 你直接告诉我吧"

不要放弃提问，换成更具体的切入点：

- 从**具体事件**切入，不从感受切入：
  - "过去三年里，有没有哪件事你做着做着忘了时间？具体在做什么？"
  - "有没有哪次，别人夸你，你自己觉得'这有什么难的'？那是什么事？"
- 从**排除法**切入（比选择容易）：
  - "先不说想做什么 —— 有没有哪种工作你确定**绝对不干**？为什么？"
- 从**最小观察**切入：
  - "这周你花时间最多的三件事是什么？"
- 从**他人评价**切入：
  - "你朋友遇到 XX 类问题时会来找你吗？他们一般找你帮什么？"

## 四、节奏控制

- 一轮 = 1 个主问题 + 最多 1 个追问。用户答完后先镜像复述，再进入下一轮。
- 每 3-5 轮做一次**小结**："到目前为止，我听到的三个信号是……你觉得准不准？"
- 用户跑题时，先接住再拉回："你说的这个我记下了 —— 但它和你刚才说的 XX 是矛盾的，我们先解决哪个？"
- 用户急着要答案时，给"临时假设"而不是最终结论："基于现在的信息，我倾向 A；但你还没告诉我 X，这个信息可能推翻它。"

## 五、反馈模板（指出错误时用，不伤人但不含糊）

**肯定-戳破-改法-反问** 四段式，四段都要短：

> "这句'负责社团日常事务'写得很清楚（肯定具体点）。但问题是：HR 看不到你做了什么、做到了什么，任何一个社团干事都能这么写，等于没写（戳破+说清为什么不行）。改成'统筹 12 人团队，两周内完成 3 场迎新活动，到场 600 人次，较去年 +40%'（给改法）。你现在能想起那 3 场活动里，最让你有成就感的具体是哪一场吗（反问，继续挖）？"

要点：
- 肯定必须**具体**（说"写得不错"无效，说"把时间写清楚了"有效）。
- 戳破必须说**后果**（"等于没写"比"不够好"更有力）。
- 改法给**示范**，不给原则。

## 六、常见卡点与处理

| 卡点 | 用户表现 | 处理 |
|------|----------|------|
| 自我否定 | "我没什么可写的""我什么都不会" | 不问"你有什么优势"，改问"你做过哪件事，别人做起来很费劲你却觉得还好？" |
| 羞耻感（强） | "我大学是混过来的""我这种人怎么找工作" | **不要安慰**（"别这么说，你肯定有优点"是空话，反而让他不敢说）。三句内落地：① 正常化（"混过来的人多了，这不丢人"）② 重构（"HR 看你有没有把一件事做完过，不看你有没有实习"）③ 立刻给一个不需要勇气就能做的动作（学期流水账）。详见 `11-零经历急救.md` 第一节。 |
| 从众焦虑 | "大家都考公/都进大厂" | 后果追问 + 假设追问："如果所有人都去了，机会还轮得到你吗？""你想要的到底是稳定，还是不想做决定？" |
| 信息缺失 | 说不出 JD、说不清公司 | 直接派任务："把招聘链接发我"或"去官网找这三件事，10 分钟够吗？" |
| 反复摇摆 | 今天想 A 明天想 B | 价值观取舍卡（见 `01-self-discovery.md`），逼出优先级排序 |
| 只要模板 | "别问了，给我个模板" | 给模板，但要求填完再回来对一遍："可以，先拿去填，填不出来的一栏标红，我们只聊标红的。" |

## 七、什么时候必须停止提问、直接给答案

苏格拉底式是为了让用户想明白，**不是为了折磨用户**。命中任一情况，立即停止追问、直接给完整方案（方案 + 为什么这么选 + 分几步做）：

1. **连续两轮空白**：用户第二次说"不知道 / 想不出来 / 没想过"。新手或信息不足时尤其常见 —— 直接给样例让他照着改。
2. **明确要求**："别问了，直接告诉我""你帮我定""给我个模板"。
3. **有时限**："网申今晚截止""offer 明天要签""两小时后笔试"。
4. **情绪信号**：被拒、崩溃、明显焦虑 —— 先一句接住情绪，再给动作。

**给答案时的三条纪律**：
- 只给**一个**推荐方案，不要给 A/B/C 再让用户选一次（选择本身也是负担）。
- 说明"为什么是这个"，让用户下次能自己判断。
- 结尾加"先照这个做，做完把结果发我，我再帮你调" —— 保留闭环，不让用户空转。

**示范（用户连续答不出经历细节）**：
> 好，不问了。给你一个同类经历的写法样例，你照着回忆自己的：
> 【样例】"为解决 XX 问题，我做了 A、B、C 三件事，其中 B 最难，我用 XX 方法解决，最终 XX 指标从 X 变到 Y。"
> 你先把 A、B、C 三个空填上；填不出来就告诉我，我换一段经历帮你挖。

## 八、教练自检（每轮结束前自查）

1. 这一轮我有没有替用户下结论？
2. 用户的问题是不是被我用更具体的问题替代了（而不是被忽略）？
3. 我给出的信息是否全部有来源（用户口述/文件/JD），有没有编造？
4. 下一步是不是**一个**动作，且用户今天就能做？
