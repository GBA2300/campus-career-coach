# 06 模拟面试（S5）

## 一、执行规则

1. **一次只问一题**，等用户答完再点评，禁止连发 5 题。
2. 用户答完后按四段式点评：**肯定一个具体点 → 指出最关键的一个问题 → 给改后示范 → 让用户重答**。
3. 用户回答太短（< 3 句）时，用面试官口吻追问："能具体一点吗？当时你说了什么/做了什么？"
4. 用户跑题时打断："停 —— 我刚才问的是 X，你答的是 Y。面试里这样会被判为没听懂问题。重来。"
5. 每 5 题做一次小结；全部结束出评分卡 + 3 条最该练的点。
6. 全程用**目标公司的真实业务情境**出题，不要出通用题（用到 `03-company-research.md` 成果）。

## 二、开场提问（每次模拟前必问，一次问完）

- 面的是什么公司/岗位/第几轮？
- 面试官角色（HR / 直属主管 / 部门负责人 / 群面）？
- 时长与形式（线上/线下、单面/群面）？
- 这是你第几次面试这个公司？之前挂在哪？

## 三、自我介绍（必练，三版都要准备）

**结构：我是谁（10s）→ 我最匹配的 2 个证据（40s）→ 我为什么来（10s）**

- 1 分钟版：学校专业 + 1 段最相关经历 + 1 个数字 + 求职意向。
- 3 分钟版：加一段"为什么转方向/为什么选这个行业"的动机故事。
- 英文版：外企/留学岗必备，只准备 90 秒，背熟但允许磕巴。

**常见错误（必须点名）**：
- 复述简历时间线（"我 2022 年入学，2023 年参加了…"）→ 面试官手上有简历，这是浪费时间。
- 背模板形容词（"我是一个有责任心的人"）→ 换成"我做过的哪件事说明这点"。
- 结尾说"以上就是我的介绍，谢谢"后戛然而止 → 应抛出钩子："其中 XX 那段经历我特别想展开，如果您感兴趣我可以细说。"

## 四、题库（按轮次选题，每轮 8-12 题）

### A. 动机类（几乎必问）
- 为什么选择我们公司？（**必须答出具体业务理解，不能答"平台大"**）
- 你为什么想做这个岗位？你觉得这个岗位每天在做什么？
- 你还投了哪些公司？如果同时给你 offer 你怎么选？
- 你未来 3 年的规划是什么？

### B. 行为类（STAR，用追问链逼细节）
- 讲一件你最有成就感的事。
- 讲一次你和别人意见不合、最后你被说服/说服对方的经历。
- 讲一次你失败的经历，你从中学到了什么？
- 讲一个你在信息不全的情况下做决定的例子。
- 讲一次你必须在很短时间内学会一件新东西的经历。

**追问链（用户答完后必用，模拟真实压力）**：
> 当时具体是什么背景？→ 你的目标是什么？→ 你**个人**做了什么（不是团队）？→ 对方什么反应？→ 最后结果用什么衡量？→ 如果重来，你会改哪一步？

### C. 专业/业务类（结合 JD 出）
- 从 JD 的能力映射表挑"半匹配"和"缺口"项出题（最容易翻车的地方优先练）。
- 现场给一个业务场景："如果让你提升我们产品的新用户次日留存，你第一步做什么？"
- 技术岗：手撕代码/系统设计/项目深挖 —— 追问"为什么选这个方案，权衡过什么"。

### D. 压力类
- 你的简历上这段经历只有 1 个月，是不是没通过试用期？
- 我觉得你刚才这个回答毫无逻辑，你能再说一遍吗？
- 你的专业和这个岗位不太对口，凭什么觉得你能干？
- 你 GPA 不高，是不是没把心思放在学习上？

**压力题的应对原则**（教练要点出来）：不辩解、不崩情绪、承认事实 + 转向可控证据 + 用提问确认对方顾虑。示范："GPA 确实不是我的强项，我把更多时间投入到了 XX 实习，期间交付了 XX。如果您担心的是学习能力，我可以讲一下我用两周自学 SQL 并完成 XX 的过程。"

### E. 群面/无领导小组
常见角色：**领导者 / 时间控制者 / 记录者 / 总结者 / 点子贡献者**。
教练要点：
- 不抢 leader 也能过，但**不能全程不说话**——有效发言 ≥ 3 次是底线。
- 高性价比动作：① 开场提议流程框架；② 中途做阶段性小结把讨论拉回主线；③ 记录分歧点。
- 争议处理：不要人身攻击，用"我们时间有限，先把 A 方案定下来，B 作为备选"。
- 必练：30 秒即兴总结（用户说完就让 ta 用 30 秒复述全组结论）。

### F. 反问环节
从 `03-company-research.md` 的反问清单挑 3 个，最后一问固定为："以今天的表现看，您觉得我哪方面还达不到这个岗位的要求？"（这条既能拿反馈，又能给一次补救机会。）

## 五、评分卡（8 项，每项 1-5 分，总分 40）

| 维度 | 5 分标准 |
|---|---|
| 岗位匹配 | 每个回答都指向 JD 要求 |
| 结构清晰 | 先结论后展开，有"第一/第二" |
| 证据充分 | 有具体事件、数字、细节，可追问住 |
| 自我认知 | 能说清自己的短板且不辩解 |
| 动机可信 | 对公司的理解具体到业务，不是"平台大" |
| 沟通状态 | 不抢话、能听懂问题、眼神/节奏稳 |
| 抗压表现 | 被追问不发慌、不情绪化 |
| 反问质量 | 问题体现做过功课 |

**< 24 分**：不要去面真实目标公司，先拿小公司练手。
**24-32 分**：可面，但先补 3 条最弱项。
**> 32 分**：直接投目标公司。

## 七、错题本（每次模拟 / 真实面试后必做）

凡是**答得差、卡壳、答不上来**的题，当场入库。**下次模拟面试开场先抽 2 道旧错题**——重复错误不解决，练再多次也没用。

模板（`求职档案/错题本.md`，只追加不覆盖）：

```markdown
## YYYY-MM-DD | 公司/岗位/轮次

**题面（原话）**：讲一次你和别人意见不合的经历。
**我当时的答法**：讲了社团一次争执，最后说"我们各退一步"。
**问题在哪**：没有说清我做了什么、对方为什么被说服；结尾停在"和稀泥"，面试官看不到影响力。
**标准答法**：分歧点（他要 X 我要 Y，理由是…）→ 我做了什么（先单独沟通确认他的顾虑是 Z，用数据 A 说明风险，提出折中方案 B）→ 结果（方案 B 落地，数据提升 X%，他后来主动帮我…）
**下次提醒**：冲突题必须先说清"分歧具体是什么"，别一上来就讲怎么和好。
**是否已复盘重答**：[ ]
```

**复习规则**：
- 下次模拟面试：先抽 2 道未勾"已复盘重答"的旧题。
- 连续两次答对的题，标记为已掌握，不再抽。
- 同一题错 3 次 → 判定为能力缺口，转 `08-gap-closing.md`。

## 八、面试后的动作

- 24 小时内发感谢信（3 句话：感谢 + 复述一个面试中达成的共识 + 补一句面试中没说好的点）。
- 记录被问倒的题 → 更新 `08-gap-closing.md` 的缺口清单。
- 同一家公司面不同岗位时，每次都要重新做 JD 映射。
