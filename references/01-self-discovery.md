# 01 自我探索与优势挖掘（S1 定位）

## 一、三环模型：目标岗位 = 喜欢 ∩ 擅长 ∩ 被需要

- **喜欢**：做什么不累、有好奇心、愿意主动花时间。
- **擅长**：同样的事你比同龄人更快/更好，或别人觉得难你觉得还好。
- **被需要**：市场愿意为此付钱，行业在招人（用招聘网站的岗位数量验证，不靠想象）。

提问顺序固定为 **擅长 → 喜欢 → 被需要**。原因：应届生的"喜欢"多为想象，而"擅长"有事实证据，先挖擅长更可靠。

追问：
- 擅长："你说的擅长，有没有一件具体的事能证明？"
- 喜欢："如果不给钱，你还会做吗？能坚持多久？"
- 被需要："在招聘网站搜这个关键词，你所在城市有多少岗位？薪资区间是多少？"

## 二、优势信号：四个来源，逐个问

1. **不费力的事**："什么事你做起来觉得顺手，别人却常夸你？"
2. **忘我的事**："有没有做着做着忘了时间的时候？那一刻你在做什么？"
3. **被求助的事**："同学/朋友遇到什么类型的问题会来找你？"
4. **学得快的事**："有没有什么技能你是自学上手、且比同期的人快的？"

每个信号都要**追到一个具体事件**才能记入素材库，否则不写进简历。

## 三、成就事件挖矿（核心工具）

一次挖一件事，按下面顺序追问，缺什么补什么：

1. 当时要解决的**问题/目标**是什么？（背景）
2. 你的**角色**是什么？团队几个人？你管谁/向谁汇报？
3. 你**个人**具体做了哪 3 件事？（逼出"我"而不是"我们"）
4. 过程中最难的**一个坎**是什么？你怎么解决的？（这是最有价值的一段）
5. 结果怎么衡量？**有数字吗**？
6. 没有数字的话：和之前比？和同学/同类项目比？有没有留下作品/截图/反馈？
7. 如果重来一次，你会在哪里做得不一样？（检验反思深度）

**挖矿顺序**（应届生按此顺序过一遍，通常能挖出 5-8 条可用素材）：
实习经历 → 课程大作业/毕业设计 → 竞赛 → 学生组织/社团 → 兼职/志愿 → 自媒体/个人项目 → 考证/自学 → 家庭责任/重大困难。

最后一条常被忽略但极有说服力（如兼职供自己读书、照顾家人后重返学业），体现韧性与责任心，**在用户同意的前提下**可考虑写入。

## 四、可迁移技能清单（供勾选，逐条要"证据"）

**信息与研究**：资料检索、竞品分析、数据分析、用户调研、文献综述、财务建模
**表达与影响**：公开演讲、写作、商务沟通、谈判、培训他人、跨部门协调、对外联络
**执行与组织**：项目管理、活动统筹、多线程推进、流程优化、预算控制、时间管理
**创造与设计**：内容创作、视觉设计、视频剪辑、产品原型、活动策划、写代码
**人际与协作**：团队协作、冲突处理、 mentoring、客户维护、社群运营
**抗压与适应**：在信息不全下决策、应对突发、长期投入一件事、失败后复盘重来

勾选后逐条追问："哪件事能证明你有这个？"—— 勾了但举不出例子的，从清单划掉。

## 五、价值观取舍卡（处理摇摆/选择困难）

给用户 12 张"牌"，强制排序并**两两取舍**：

> 高薪 / 稳定 / 成长快 / 离家近 / 工作内容有趣 / 团队氛围好 / 公司名气大 / 工作生活平衡 / 社会价值 / 明确的晋升路径 / 能用到我的专业 / 有自由度

操作：
1. "先挑出你最在意的 5 张。"
2. "现在只剩 3 个名额，扔掉 2 张 —— 扔掉哪两个？为什么？"（逼出真实权重）
3. "如果 A 满足前 3 张但钱少 30%，B 钱多但都不满足，你选哪个？"（检验）

## 六、考研 / 考公 / 就业 / 留学：判断框架

不替用户决策，只问这 6 个问题并要求用户逐条回答：

1. 你考研是因为**想做某件必须读研才能做的事**，还是因为不想面对求职？
2. 目标岗位的实际招聘要求里，研究生学历是**硬性门槛**还是加分项？（去招聘网站查 20 个 JD 验证）
3. 如果考不上，你的 Plan B 是什么？能接受吗？
4. 你能接受的最长备考周期是多久？期间的**时间成本和经济成本**你算过吗？
5. 三年后你希望简历上多出什么？现在这条路能给你吗？
6. 有没有第三条路（先就业再读非全、先实习再看、考公+秋招并行）？

然后让用户自己说结论，教练只负责指出**逻辑漏洞**和**没算的成本**。
