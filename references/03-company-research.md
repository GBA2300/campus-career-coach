# 03 公司背调（S3）

## 一、六个必查维度（按重要性排序）

1. **它怎么赚钱**：主营业务、收入来源、客户是谁。看不懂的业务不要投。
2. **行业位置与趋势**：头部/腰部/创业期、主要竞对、近两年是扩张还是收缩（裁员/关业务线新闻）。
3. **近期动态**：近 6 个月融资、新品、财报、重大合作、负面新闻。
4. **组织与团队**：目标部门在公司内的位置（核心业务 or 边缘）、团队规模、汇报线。
5. **招聘信号**：同岗位是否在多个平台长期挂、招几个人、薪资区间、近年来校招规模。
6. **风险信号**：欠薪/劳动纠纷/被执行/大量差评、试用期淘汰率高、外包或派遣。

## 二、信息源清单（只用公开信息）

| 目的 | 渠道 |
|------|------|
| 业务与财报 | 官网/投资者关系页/年报/招股书 |
| 工商与风险 | 国家企业信用信息公示系统、天眼查、企查查（看参保人数、诉讼、被执行） |
| 员工口碑 | 脉脉、看准、职友集、牛客网（校招面经最多） |
| 业务动态 | 公司公众号、36氪/虎嗅、行业媒体、应用商店评论 |
| 岗位真实度 | BOSS直聘/拉勾/猎聘同岗位横向对比、牛客面经 |
| 产品体验 | 亲自用一遍它的产品/服务，面试时能说出 1 个优点 + 1 个可改进点 |

**只查公开信息，且只用免费版本**：天眼查 / 企查查 / 脉脉的免费额度足够做背调，**不要为了背调开会员**；需要更细的信息时，改从招聘平台、官网年报、牛客面经这些完全免费的渠道补。

**判读规则**：单个负面评价不算数，同一问题被 3 个以上不同人反复提到才算信号。

## 三、30 分钟快速背调 SOP

1. **5 分钟**：官网 + 最近一条财报/融资新闻 → 一句话说清"它靠什么赚钱"。
2. **5 分钟**：招聘平台搜同岗位 3 家竞对 → 确认薪资区间与要求是否合理。
3. **10 分钟**：牛客/脉脉搜公司名 + 关键词（"加班""氛围""离职""转正"）→ 记高频词。
4. **5 分钟**：体验产品/服务，记 1 个优点 1 个槽点。
5. **5 分钟**：写 3 个必须问面试官的问题。

## 四、反问面试官清单（挑 3 个，最后一问必留"我还有什么要改进"）

**问团队与工作**：
- 这个岗位日常的一天大概是怎样的？前三个月最主要的产出是什么？
- 团队现在几个人，我来了向谁汇报，和谁配合最多？
- 这个岗位是新增还是替补？上一任为什么离开？（重要但语气要自然）
- 这个岗位做得好的人，一年后通常是什么样？

**问成长与评价**：
- 公司对这个岗位的考核标准是什么？多久评估一次？
- 团队里校招生一般多久能独立负责一块业务？
- 公司在校招生培养上有什么具体机制（导师制、轮岗、培训）？

**问业务与风险（显示你做过功课）**：
- 我注意到贵司最近在 XX 方向有动作，这个岗位会参与其中吗？
- 目前这个业务最大的挑战是什么？
- 团队现在最缺什么样的人/能力？

**别问**：官网首页就能查到的、薪资结构细节（留到 HR 面）、"你们公司好不好"。

## 五、风险红旗（出现即提示用户谨慎）

- 面试流程极短、当天发 offer、催签三方 → 可能流动性极大。
- 拒绝书面 offer、薪资只口头说、五险一金基数按最低缴 → 不规范。
- 要求交"培训费/押金/体检指定机构付费" → **直接劝退**，属违规。
- 岗位描述与面试内容严重不符（如面试变销售/贷款/保险推销）→ 提示离场。
- 大量"我们就是要能吃苦、能加班"而无具体业务说明 → 慎选。
- 签三方前要求先交违约金条款不合理（超过一个月工资通常偏高）。

```markdown

## 口碑高频词（正面/负面各3）

## 我的判断（去/不去/待定 + 理由）
## 反问清单（3个）
```
