# 09 网申、性格测评与笔试（S7）

> 这一关最容易让"简历很好"的人莫名其妙被刷。全部方案只用免费渠道。

## 一、网申表单填写（15 条硬规则）

1. **先复制到本地再写**：把表单题目抄到记事本写好，再粘贴进去。网页超时会丢稿，这是最常见的翻车。
2. 所有必填项填完；没有的一律写"无"或"暂无"，**不要空着**（很多系统把空值判为未完成）。
3. **与简历严格一致**：公司名、时间、岗位名、GPA，网申和简历对不上会被判定为造假。
4. 时间格式按系统要求（YYYY/MM 还是 YYYY.MM），起止月份不要出现空档（空档写清楚在做什么）。
5. 开放题**不要复制自我评价**，用 CAR（背景-动作-结果）写，控制在字数上限的 80-95%（写满说明你重视，超出会被截断）。
6. 每段开放题**只讲一个故事**，不要塞三件事。
7. 一个素材库管所有公司：同一道题换个公司名和岗位关键词即可复用，**但"为什么选择我们"必须每家重写**。
8. 附件：PDF 格式，文件名 `姓名-岗位-学校.pdf`，控制在 2MB 内（超过先压缩，不要传 Word）。
9. 照片按 JD 要求上传，尺寸不符先用系统「照片」应用裁剪，避免变形。
10. 邮箱别填错（错一个字母 offer 就收不到）；**投递后 2 小时内查一次收件箱和垃圾邮件**。
11. 用 PC 端 Chrome/Edge，别用手机网申（排版错乱、附件传不上）。
12. 记录每一家的：投递时间、渠道、账号、网申截止时间、开放题原题（进 `进度看板.md`）。
13. 同一公司**不要重复投递多个岗位**（会被标记），想投第二个岗位等第一个流程结束。
14. 内推码/推荐人一栏：没有就空着或写"无"，**不要编造**。
15. 提交前用 `read_resume.py` 或肉眼核对一遍：手机号、邮箱、意向城市。

## 二、开放题（OQ）五类母题 + 答题骨架

| 母题 | 骨架 | 素材来源 |
|---|---|---|
| 为什么选择我们公司/岗位 | 业务理解（具体到某条产品线/某次动作）+ 我的哪段经历正好匹配 + 我能带来的第一件事 | 公司背调 + JD 拆解 |
| 最有成就感的一件事 | 情境与目标 → 我做的 3 个动作 → 数字结果 → 复盘学到什么 | 素材库 TOP1 事件 |
| 团队合作 / 冲突处理 | 分歧是什么 → 我怎么理解对方立场 → 我做了什么促成共识 → 结果 | 素材库 |
| 克服困难 / 失败经历 | 困难具体化 → 我尝试了什么 → 哪里判断错了 → 改了什么 → 后来结果 | 素材库（**必须真有失败，不要编"假失败"**） |
| 领导力 / 影响力 | 没有正式职权时如何推动 → 你用什么说服 → 结果 | 社团/项目经历 |

**判卷人看什么**：结构清晰度 > 真实性 > 数字 > 与公司业务的关联。写完大声读一遍，读着拗口就改。

## 三、性格测评（SHL / 游戏化 GBA / 大五人格等）

**四条原则**（照做即可，不用研究理论）：

1. **真实偏正向**：选"更符合你的"，但倾向积极、合作、有责任感的那一侧。
2. **前后一致**：同一维度会反复问（换措辞），前后矛盾会触发"不一致"标记 —— 这是被刷的主因。
3. **不要全选中立**：大量"一般/不确定"会被判为缺乏自我认知或敷衍。
4. **极端题慎选**："我从不犯错""我总是第一个完成"这类绝对项选"比较符合"比"完全符合"安全。

**类型与练法（全部免费）**：
- 数字/逻辑/图形推理（SHL、Cut-e）：牛客网「笔试练习」免费题库、粉笔网行测免费题。
- 游戏化测评（GBA / 海底捞式小游戏）：B 站搜"GBA 测评"看规则讲解视频；关键是**保持稳定策略**，不要前几轮冒险后几轮保守。
- 情景判断（SJT）：记住"先沟通确认 → 按流程上报 → 主动承担"的优先级。

## 四、行测（互联网/国企/银行通用）

**题型与优先级**（时间不够就按这个顺序放弃）：

1. 资料分析（**性价比最高**，20 题全对可拉开差距，练速算与找数）
2. 判断推理（图形/定义/类比/逻辑，套路固定）
3. 言语理解（选词、片段阅读，靠语感 + 关键词）
4. 数量关系（**最耗时**，先跳过，最后蒙）
5. 常识（日常积累，不要专门准备）

**免费练题**：牛客网（笔试/行测题库，免费）、粉笔（行测免费题库 + 每周模考）、学习强国（常识）、目标公司往年真题在牛客/应届生论坛搜（免费）。

## 五、专业笔试

- **技术岗**：LeetCode 免费题库（按"公司 + 高频"标签刷）、牛客网真题、剑指 Offer。重点不是刷量，是**把做过的题能讲清思路和复杂度**。
- **产品/运营**：常见题型为案例分析（"如何提升某产品次日留存"）、数据分析题、写 PRD/方案。练法：按 `02-jd-decoding.md` 的能力项各准备 1 个分析框架。
- **财务/审计**：会计分录、Excel 实操、CPA 相关基础。
- **银行/国企**：行测 + 综合知识（经济金融基础 + 时政 + 该行常识）。

## 六、笔试前 24 小时清单

- [ ] 确认时间（**注意时区，外企常写 UTC/美东时间**）、时长、是否开摄像头、是否允许计算器/草稿纸。
- [ ] 设备：充满电、关掉弹窗通知、准备有线网（WiFi 掉线最致命）、手机放远处。
- [ ] 环境：桌面只留笔和纸，双机位按通知提前搭好。
- [ ] 提前 15 分钟进系统，用测试链接验证摄像头与网络。
- [ ] 错题本里同类题过一遍。

## 七、被刷之后

不要急着怀疑自己。先判断是**能力问题**还是**流程问题**：行测刷掉通常是熟练度，练 3 套就能提；性格测评刷掉多为不一致，下次答题策略稳定即可；专业笔试刷掉才是真缺口 → 转 `08-gap-closing.md`。
