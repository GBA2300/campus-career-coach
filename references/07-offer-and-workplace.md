# 07 Offer 选择、薪资谈判与职场初期（S6）

> 原则：给框架和提问清单，**不下绝对结论**。签约前提示用户核对学校就业指导中心规定。

## 一、Offer 比较：10 维度加权表

让用户自己打分（1-5）并**自己填权重**，教练只负责指出漏掉的维度。

| 维度 | 为什么重要 | 权重 | A公司 | B公司 |
|---|---|---|---|---|
| 岗位内容与成长 | 前 2 年学东西的速度决定第 3 年的身价 | | | |
| 直属领导 | 比公司名气更影响你前 3 年 | | | |
| 团队稳定性 | 一年内换 3 个 leader 的团队慎入 | | | |
| 薪资总额（年包） | 见下方拆解 | | | |
| 薪资结构风险 | 绩效/年终占比越高，实际到手不确定性越大 | | | |
| 城市与生活成本 | 到手 - 房租 - 通勤 | | | |
| 行业与业务前景 | 增长中的业务 = 更多机会 | | | |
| 公司品牌与跳板 | 第一份工作的品牌影响第二份 | | | |
| 工作强度 | 用"日均时长 + 周末"具体化，别看口号 | | | |
| 转正与晋升确定性 | 校招生转正率、晋升周期 | | | |

**必问用户的三个问题**：
1. "这两个 offer，如果三年后回头看，哪一个让你更可能不后悔？"
2. "你最在意的那一栏，是**真的在意**，还是因为别人也在意？"
3. "如果 A 公司给你现在这个薪资的一半，你还想去吗？"（检验兴趣真伪）

## 二、薪资拆解（不要让"月薪"骗了）

**年包 = 月薪 × 发放月数 + 绩效/奖金 + 年终 + 补贴 + 股票/期权（按流动性打折，通常按 0-50% 计）+ 公积金（公司部分也算钱）**

必问清的 6 件事（给用户做成提问清单，让 ta 直接问 HR）：
1. 月薪是税前还是税后？一年发几个月（13 薪 / 14 薪）？
2. 绩效奖金怎么算？历史上实际发放比例大概是多少？
3. 年终奖的考核周期与发放时间（次年 4 月发 = 提前离职可能拿不到）。
4. 五险一金缴纳基数和比例（**按最低基数缴 vs 按实际工资缴，差距可达月薪的 15-20%**）。
5. 试用期时长、薪资是否打折（法律规定不得低于转正的 80% 且不得低于当地最低工资）。
6. 是否有签字费、住房补贴、餐补、加班费/调休。

**加班折算**：月薪 12k、每天加班 2 小时 vs 月薪 10k、准点下班 —— 时薪反而是后者高。把年包除以"年实际工作小时"再比。

## 三、谈判话术（HR 面 / 谈薪阶段）

**原则**：
- 先让对方出价，**不要先报数**。被问期望薪资时给区间，且区间下限 = 你真实期望值。
- 每个诉求都要有**外部依据**：同类岗位市场价、另一份 offer、具体能力证据。
- 只谈一次深度，不要反复拉扯。谈完确认书面。

**话术示范**：
- 开场："我对这个岗位很感兴趣，也想确认一下薪酬这块，看我们能不能对齐。"
- 被问期望："结合市场上同类岗位（我了解到大致在 X-Y）以及我在 XX 上的经验，我期望在 Y 左右，具体可以看整体的薪酬结构。"
- 拿到低于预期的 offer："我很想加入，但这个数字和我手上的另一个 offer 有差距。如果在 base 上不方便，年终/签字费/职级方面是否有空间？"
- **不要说**："我同学拿了多少"（无效）、"我生活压力大"（无效）、"不给就不来"（威胁，除非真有底气）。

## 四、三方协议 / 两方 / Offer Letter（要点）

- **三方协议（就业协议书）**：学校、学生、用人单位三方，具有一定的约束力；违约金条款要**看清金额与适用情形**。
- 违约金一般不应畸高（超过一个月工资通常偏高，可尝试协商下调）。
- 签三方前确认：岗位、工作地点、薪资、落户/档案/户口办理、体检要求、入职时间、违约条款。
- **Offer Letter** 要书面（邮件/纸质），包含岗位、薪资、入职日期、有效期。
- 已签三方又想毁约：尽早沟通、按协议赔付、向学校就业指导中心了解流程（一般有一次违约机会，但各校规定不同）。
- 劳动合同：入职一个月内必须签；试用期包含在合同期内，合同期 1-3 年试用期不超过 2 个月，3 年以上不超过 6 个月；**试用期也要缴五险一金**。

## 五、试用期与入职 90 天

**试用期被淘汰的常见原因**（提前告诉用户）：
1. 只做被安排的事，不主动确认期望。
2. 遇到问题不问，憋到 deadline 才发现做错了。
3. 不会写工作汇报，领导看不到进展。
4. 与协作方关系搞僵。
5. 没搞清楚考核标准就埋头干。

**90 天行动清单**：
- 第 1 周：搞清"我这个岗位被考核什么"，直接问 leader："三个月后您希望我做到什么程度算合格？"
- 第 2-4 周：交付 1 个小而可见的成果。
- 每周五发一封 5 行周报（本周完成 / 下周计划 / 卡点 / 需要的支持）。
- 建立 3 个关键关系：直属 leader、一个协作部门对接人、一个同期入职的伙伴。
- 第 60 天主动要一次反馈。

## 六、职场常见问题（苏格拉底式处理，先问后答）

| 场景 | 先问 | 再给框架 |
|---|---|---|
| 被边缘化、没活干 | "你主动要过活吗？怎么要的？" | 主动认领小任务 + 周报刷存在 + 约 leader 1v1 问期望 |
| 加班严重 | "加班是真的工作量，还是流程/等待造成的？" | 区分可控与不可控；提效率方案；长期看是否换岗/换公司 |
| 和领导不合 | "你和 ta 的分歧，是目标不同还是方法不同？" | 目标不同则对齐期望；方法不同则先执行后提建议；持续不合考虑转岗 |
| 想转岗/跳槽 | "你想逃开什么，还是奔向什么？" | 逃开型跳槽易重蹈覆辙；先内部转岗试水，满 1 年再跳（频繁跳槽伤简历） |
| 被批评/背锅 | "这件事里，你确实没做到的部分是什么？" | 先认自己那部分 → 澄清事实（对事不对人）→ 给改进动作 → 书面留痕 |
| 薪资倒挂/涨薪 | "你过去半年有什么可量化的产出？" | 用成果谈，不用苦劳谈；准备外部市场价；选对时机（考核后/项目交付后） |
