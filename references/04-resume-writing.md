# 04 中文简历写作规范（S4 核心）

## 一、简历的本质：一份"证据清单"，不是自我介绍

HR 初筛一页简历平均 7-10 秒。简历唯一的使命是**拿到面试**，不是全面展示人生。因此每一行的取舍标准只有一个：**这一行能不能增加我被约面的概率？** 不能就删。

给用户立这条标准后，所有"要不要写"的争论都有了解法。

## 二、模块顺序（应届生默认，可调整）

1. 个人信息（最简）
2. 教育背景
3. 实习/工作经历（最重要，篇幅最大）
4. 项目经历（技术研究岗提到实习前）
5. 校园/社会实践（实习少时放大）
6. 技能与证书
7. 荣誉奖项
8. 自我评价（**可选**，写得空不如不写）

**排序原则**：把最能证明 JD 要求的模块往前放。
- 有 2 段以上相关实习 → 实习放教育之后，甚至教育简写一行。
- 技术岗无实习但有硬核项目 → 项目在前。
- 学生会社团经历丰富但无实习 → 校园实践改名"项目经历"写，按项目标准写（目标-动作-结果）。

## 三、个人信息：只写这些

姓名、手机号（写成 `138-0000-0000` 便于拨打）、邮箱（**不要用 QQ 邮箱的默认昵称**，改成姓名拼音@）、所在城市/意向城市、政治面貌（国企/事业单位/选调需要）、年龄或出生年月（国企需要）、求职意向（**必须写，且只有一个**）。

**不写**：身高体重、婚育、民族（除非岗位要求）、详细家庭住址、身份证号、"个人简历"四个大字当标题（用姓名即可）、星座血型。

照片：**有则放右上角**。规格见 SKILL.md 3.2。技术岗、远程岗、外企可省；销售/教师/空乘/国企/事业单位/文职建议放。

## 四、Bullet 写法：CAR 公式 + 量化

**公式**：`动作动词 + 具体内容/对象 + 方法/工具 + 可量化结果`

- 弱："负责社团的日常管理工作。"
- 中："负责社团 12 人团队的日常管理，组织 3 场迎新活动。"
- 强："统筹 12 人团队策划 3 场迎新活动，通过提前 2 周排期与分工看板压缩筹备周期，到场 600 人次（较去年 +40%），活动满意度 4.6/5。"

**每段经历 3-5 条 bullet**，最多不超过 6 条；最重要的放第一条。每条 1-2 行，不超过 2 行。

**量化五法**（用户说"没法量化"时逐个套用）：
1. **绝对值**：人数、金额、场次、条数、代码行数、文档页数。
2. **增幅**：从 X 到 Y（+Z%）。
3. **占比/排名**：占全部门 30%、年级前 5%、团队第一。
4. **对比**：比上次快 2 天、比同学组高 15 分、是同类活动平均的 2 倍。
5. **效率/成本**：节省 8 小时/周、成本降 20%、错误率从 5% 降到 1%。

实在没有数字的，用**事实对比**或**可验证产物**（附链接/作品集）："输出 3 万字行业研究报告，被导师作为课程范例"。

## 五、动词库（按场景，禁止使用"负责/参与/协助/帮忙"单独成句）

**领导与推动**：主导、统筹、牵头、发起、重构、推动、从 0 搭建
**分析与研究**：分析、拆解、调研、建模、复盘、归因、评估、诊断
**增长与运营**：策划、落地、拉新、转化、留存、优化、提升、裂变
**执行与交付**：独立完成、交付、按期完成、迭代、上线、标准化
**协作与影响**：协调、对接、说服、培训、跨部门推动、维护
**降本增效**：缩短、压缩、减少、自动化、节省、提高

规则：一条 bullet **只用一个强动词开头**；同一个动词在全篇不超过 3 次。

## 六、"为什么这么写 / 作用是什么"对照表（给用户解释时用）

| 写法 | 为什么 | 作用 |
|---|---|---|
| 求职意向只写一个岗位 | 多目标 = 无目标，HR 无法归类 | 提高被分配到正确岗位池的概率 |
| 经历按时间倒序 | HR 默认从最近看起 | 让最新、最相关的经历先被看到 |
| 用 JD 原词（如"用户增长"） | 大厂用 ATS 关键词初筛 | 通过机器筛选，不被漏掉 |
| 结果写数字 | 数字是唯一无法吹牛的证据 | 在 8 秒内形成记忆点，制造提问钩子 |
| 主语省略/用"我"，不写"我们" | HR 只招你一个人 | 明确个人贡献，避免被判定为蹭团队成果 |
| 课程只写 3-5 门且必须与岗位相关 | 无关课程是噪音 | 强化专业匹配度，不浪费版面 |
| 删掉"自我评价：勤奋好学踏实肯干" | 无证据支撑，人人可写 | 空出 3 行放一个真实成果 |
| 一页纸 | 应届生经历撑不满两页 | 倒逼删废话，提高信息密度 |
| 导出 PDF 投递 | Word 在不同设备排版会乱 | 保证 HR 看到的就是你设计的样子 |
| 文件命名"张三-新媒体运营-xx大学.pdf" | HR 一天下载上百份 | 不因文件名叫"简历最终版3"被埋没 |

## 七、禁忌清单（逐条对照检查，犯一条扣一分）

1. 用"负责/参与/协助"开头的空 bullet。
2. 通篇没有数字。
3. 主语是"我们"。
4. 写"熟练掌握 Office/Photoshop"却没有任何使用证据。
5. 罗列 15 门课程名占半页。
6. 兴趣爱好写"读书、旅游、音乐"（除非有成果，如"马拉松完赛 3 次"）。
7. 自我评价写形容词堆砌（若有，必须每一句都跟一个事实）。
8. 时间顺序错乱或时间线对不上（写出空档期会被追问）。
9. 一页写满但信息量为零 —— 典型症状：字号 10.5、行距 1.0、全是套话。
10. 有错别字、公司名写错、中英文标点混用。
11. 用 QQ 邮箱默认昵称（如 "孤狼@xx.com"）。
12. 同时写"求职意向：运营 / 产品 / 人力 / 行政"。
13. 经历时间与学期冲突（如"2024.09-2025.01 全职实习"但同期在上课且不说明）。
14. 简历中出现"薪资要求面议"或大段个人家庭情况。
15. 照片是自拍/生活照/多人合照裁切/过度美颜。

## 八、排版与交付

- 一页（应届生默认）。内容确实超过一页时：删，而不是缩小字号。
- 正文字号 10.5-11pt，中文正文宋体/思源宋体，标题黑体；全篇颜色不超过 2 种（黑 + 一个深色点缀）。
- 页边距 ≥ 1.5cm；段落间距统一；左侧对齐，不用居中排版（除姓名标题）。
- 用项目符号不用表格（ATS 解析表格差）；不要用文本框/页眉页脚放关键信息（部分 ATS 读不到）。
- 投递格式：**PDF**，文件名 `姓名-应聘岗位-学校.pdf`。招聘方明确要求 Word 时再发 .docx。
  转 PDF 用 `scripts/export_pdf.py`（本地免费）；本机没有 LibreOffice/Word/WPS 时，让用户用 Word/WPS「另存为 PDF」，或装开源免费的 LibreOffice、用 PDF24 在线免费档。**不要推荐任何付费工具。**
- 作品集/项目链接用可点击的短链或二维码，不要贴长 URL。

## 九、不同岗位的侧重（快速对照）

| 岗位类型 | 简历第一屏必须出现 |
|---|---|
| 互联网运营 | 数据增长结果、内容/活动作品链接 |
| 产品 | 需求文档/原型链接、用户调研结论、项目上线数据 |
| 技术开发 | GitHub/技术博客、项目技术栈与难点、代码量/性能提升 |
| 市场/品牌 | 传播量、媒体资源、策划案 |
| 财务/审计 | 相关实习（四大/八大优先）、证书进度（CPA 通过科目） |
| 人力 | 招聘/培训/员工关系具体案例与人数 |
| 教师/教育 | 教师资格证、试讲/支教经历、学生成绩提升数据 |
| 国企/银行 | 政治面貌、成绩排名、校级荣誉、稳定性信号 |
| 快消/管培 | 领导力事件、跨部门协作、校园影响力 |
